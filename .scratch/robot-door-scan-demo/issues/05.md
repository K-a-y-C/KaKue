# Select ordered door surface points and inspect coordinates

GitHub issue: https://github.com/K-a-y-C/KaKue/issues/5
Label: ready-for-agent

## What to build

Click visible door surfaces to append numbered markers and matching coordinate/status rows, preserving part-local and robot-base positions and approach-side normals.

**User stories covered:** 13–18 (numbering from the PRD).

This is a vertical slice of the Robot Door Scan Demo: a desktop web app showing the supplied articulated six-axis robot and a fixed door, selecting surface points, simulating verified scanner visits, and downloading PLY/CSV plus unchanged STEP. It is a local-browser simulation; no backend, database, accounts, real scanner/controller, collision planning, or persistence is required.

User-story numbers and specification headings are preserved in both versions. Also read the [agent implementation guide](https://github.com/K-a-y-C/KaKue/blob/codex/concise-prd/docs/agents/implementation-guide.md), [robot verification](https://github.com/K-a-y-C/KaKue/blob/main/docs/research/robot-verification.md), and every blocker below. These contain the domain vocabulary, full constants/contracts/state machine, source identity, and acceptance gates; no prior chat context is needed.

## Acceptance criteria

- [ ] A stationary click adds exactly one surface hit; duplicates remain separate, append-only points. Show XYZ in robot-base millimeters to one decimal place.
- [ ] Reject drags exceeding 5 CSS pixels, multitouch, release outside canvas, non-door objects and empty window openings. Raycast only actual door geometry; no vertex snapping.
- [ ] Transform/renormalize mesh-derived normals, orient toward the selected side and retain the sign. Camera changes cannot change stored coordinates.
- [ ] Incremental browser tests cover known hits and ignored interactions; an independent rigid-transform fixture verifies coordinates within 5 mm.
- [ ] Record reproducible verification commands/results and deliverable evidence; provide a concise handoff identifying contracts introduced and the next unblocked work. Do not close with unverified mandatory acceptance gates.
