## What to build

Verify the user-supplied replacement STEP door and prepare a reproducible asset manifest/cache so the actual door can enter the demo and later be downloaded unchanged. This is an independently verifiable asset prerequisite; no CATPart conversion is needed.

**User stories covered:** 3, 7, 38 (numbering from the PRD).

This is a vertical slice of the Robot Door Scan Demo: a desktop web app showing the supplied articulated six-axis robot and a fixed door, selecting surface points, simulating verified scanner visits, and downloading PLY/CSV plus unchanged STEP. It is a local-browser simulation; no backend, database, accounts, real scanner/controller, collision planning, or persistence is required.

**Read before implementation:** the complete [PRD](https://github.com/K-a-y-C/KaKue/blob/main/.scratch/robot-door-scan-demo/PRD.md), [agent implementation guide](https://github.com/K-a-y-C/KaKue/blob/main/docs/agents/implementation-guide.md), [robot verification](https://github.com/K-a-y-C/KaKue/blob/main/docs/research/robot-verification.md), and every blocker below.
